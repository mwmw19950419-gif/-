# 化粧品アレルギーの原因を皮膚科のパッチテストで調べる　受診の準備から、結果を買い物に生かすまで

## 今、こんな場面で止まっていませんか

新しい化粧品に替えるたびに、顔が赤くかゆくなる。原因が分からないので、肌に優しいと書かれた物を次々に試しては、また荒れる。皮膚科で「パッチテストで原因を調べられる」と聞いたが、何日かかるのか、何を持っていけばいいのか分からない。この記事は、検査を受ける病院探しから、結果をもとに化粧品を選べるようになるまでを進めます。

## この記事が向いていない人

- 化粧品を使ってすぐ、顔が大きく腫れた、息苦しいなどの症状が出た人。すぐに医療機関を受診してください。
- 今、肌に強い症状が出ている人。症状が強いときは、検査を後回しにすることがあります。先に治療を受けます。
- 食べ物や花粉のアレルギーを調べたい人。この記事の検査は、肌に触れる物によるかぶれを調べるものです。

## 全体像：6ステップ、通院は4〜5回で終わります

パッチテストは、かぶれの原因になりやすい成分や、自分が使っている化粧品を背中などに貼り、反応を見る検査です。肌に触れた物で起きるかぶれ（アレルギー性接触皮膚炎）の原因を調べます。

1. 検査をしている皮膚科を探す
2. 使っている物を集め、一覧表を作る
3. 初診で相談し、検査の日を決める
4. 検査の期間を過ごす（貼る日から約1週間）
5. 結果を聞き、避ける成分を書き出す
6. 結果をもとに、化粧品を選び直す

通院の流れは、例えば次のようになります。判定の日は医院によって違います。

| 通院 | 日の例 | やること |
|---|---|---|
| 初診 | 検査の1〜2週間前 | 相談し、検査の日を決める |
| 1回目 | 月曜 | 背中に貼る |
| 2回目 | 水曜（2日後） | はがして、1回目の判定 |
| 3回目 | 木曜か金曜 | 2回目の判定 |
| 4回目 | 翌週の月曜（1週間後） | 最後の判定と、結果の説明 |

初診と1回目を同じ日にする医院もあります。

貼ってからの1週間ほどは、背中を濡らせない、汗をかく運動を控えるなどの決まりがあります。初診の前に、手帳かカレンダーを見て、仕事や旅行と重ならない週を2つ候補として選んでおきます。

### この先の有料部分に入っているもの

- 状況別の進め方（原因の候補が多い／特定の化粧品が怪しい／仕事で使う物が原因かもしれない）
- ステップ1〜6の手順。検査をしている皮膚科の探し方、持っていく物、検査中の過ごし方
- 汗、かゆみ、全部陰性だったときなど、つまずきやすい5か所と対処
- そのまま使える書式3つ（使っている物の一覧表／受診のときのメモ／結果をもとにした「避ける成分」のカード）
- 結果を生かせているかを、3か月後に確かめる方法

ーーー ここから有料 ーーー

## 状況の分かれ方：あなたはA・B・Cのどれですか

### A 原因の候補が多い

何を使っても荒れる人です。かぶれの原因になりやすい成分をまとめて調べる検査（ジャパニーズスタンダードアレルゲン、ジャパニーズベースラインシリーズなどと呼ばれる）を中心に受けます。使う検査の種類は医院によって違います。自分の化粧品も一緒に貼るかは、医師と決めます。

### B 特定の化粧品が怪しい

「このクリームを使うと荒れる」と見当がついている人です。その化粧品そのものを貼る検査（持参品のパッチテスト）ができるか、初診で聞きます。洗顔料やシャンプーなど洗い流す物は、そのまま貼ると刺激が強すぎるため、薄めて貼るなどの工夫が要ります。薄め方は医師が決めます。自分で薄めて持っていくことはしません。

### C 仕事で使う物が原因かもしれない

美容師のカラー剤、医療職の手袋や消毒液、工場の油など、仕事で触れる物が怪しい人です。初診で職業と、触れる物の名前を具体的に伝えます。仕事が原因と分かった場合、労災保険（仕事が原因のけがや病気を補償する国の保険）の対象になることがあります。手のかぶれの人は、別記事「仕事による手荒れ」のステップ4で、職場への相談の仕方を扱っています。

## ステップ1 検査をしている皮膚科を探す

パッチテストは、すべての皮膚科で受けられるわけではありません。次の順で探します。

1. 今かかっている皮膚科に電話し「化粧品のパッチテストはできますか」と聞く
2. できない場合は、検査ができる病院への紹介状を書いてもらえるか聞く
3. 自分で探す場合は、医院のホームページの「診療内容」のページで「パッチテスト」の文字を探す。日本皮膚免疫アレルギー学会のホームページも、探す手がかりになります

電話で確かめることは4つです。

- かぶれやすい成分をまとめて調べる検査ができるか
- 自分の化粧品を持ち込んで貼れるか
- 貼る日を何曜日にしているか
- 費用の目安（保険が使えるかは、検査の内容によります）

## ステップ2 使っている物を集め、一覧表を作る

顔や体に使っている物をすべて集め、書式1の一覧表に書きます。化粧品のほかに、次の物も入れます。

- シャンプー、コンディショナー、ヘアカラー剤
- 日焼け止め、ハンドクリーム、リップ
- 塗り薬、湿布
- 洗濯洗剤、柔軟剤
- ピアス、ネックレスなどの金属

例）「化粧水　〇〇（商品名）　使い始め：今年5月　症状：使った翌日に赤み」

現品と、全成分の表示がある箱は捨てずに残します。持参品の検査で使うことがあるからです。

## ステップ3 初診で相談し、検査の日を決める

初診では、書式2のメモを医師に見せます。症状が出た場所、時期、使い始めた物を順に伝えます。

検査の日は、次の3つを満たす週を選びます。

- 貼ってから1週間、背中を濡らさずに過ごせる
- 激しい運動や、汗をたくさんかく予定がない（夏の実施を避ける医院もあります）
- 判定の日に、毎回通院できる

今飲んでいる薬（かゆみ止め、ステロイドの飲み薬など）は、結果に影響することがあります。お薬手帳を見せて、検査の前に止める必要があるか聞きます。自分の判断では止めません。

## ステップ4 検査の期間を過ごす

貼る日は、背中を出しやすい服で行きます。背中に、成分をしみこませたシールを何枚も貼り、ペンで印をつけます。

検査中の決まりの例です。実際には医院の指示に従います。

- シャワーは下半身だけにして、背中は濡らさない
- 汗をかく運動、サウナ、長い入浴は控える
- 貼った場所をかかない、こすらない
- シールがはがれないよう、ゆったりした服で寝る

はがれかけても、自分で貼り直しません。医院に電話して指示を聞きます。

## ステップ5 結果を聞き、避ける成分を書き出す

判定の日ごとに、医師が反応の出た場所と強さを記録します。最後の判定の日に、結果の説明を受けます。

聞き漏らさないよう、書式2のメモの「結果の日に聞くこと」を持っていきます。聞くのは次の3つです。

- 反応が出た成分の名前と、化粧品の成分表示で使われる名前
- その成分が入っていそうな製品の種類
- 一緒に避けたほうがよい、似た成分があるか

結果を紙でもらえるかも聞きます。もらえない場合は、成分名をその場で正確に書き取ります。

例）「パラフェニレンジアミン（ヘアカラーの染料）に陽性」「香料ミックスに陽性」

## ステップ6 結果をもとに、化粧品を選び直す

結果から、書式3の「避ける成分」のカードを作ります。財布に入れ、スマホでも写真を撮っておきます。

化粧品を買うときは、パッケージ裏の「全成分」の欄に、カードの成分がないか探します。通販では、商品ページの「全成分」や「成分」の項目を見ます。店頭と通販での探し方は、別記事「敏感肌の人が化粧品の成分表示を読む」のステップ3・4で扱っています。

美容室やネイルサロンには、予約のときと来店したときにカードを見せます。

## つまずきやすい箇所と、その対処

1. **検査中に背中がかゆくてたまらない**：強いかゆみは、反応が出ているしるしのことがあります。かかずに、医院へ電話して指示を聞きます。
2. **汗でシールがはがれた**：自分で貼り直すと、正しく判定できません。医院に電話し、貼り直すか、日を改めるかを聞きます。
3. **全部陰性だった**：今回調べた成分では、反応が出なかったという結果です。荒れる原因をほかに探すため、医師と相談します。
4. **陽性の成分名が、化粧品の表示に見当たらない**：検査で使う名前と、化粧品の表示名が一致しないことがあります。結果の説明のときに「化粧品の表示では何と書かれますか」と聞きます。
5. **同じ成分の物をまた買ってしまう**：カードの写真を、スマホの写真アプリの「お気に入り」に入れます。買う前に開く場所を決めておきます。

```

日焼け止め ｜ ＿＿＿＿ ｜ 〇年〇月 ｜
```

### 書式2 受診のときのメモ

```
〇月〇日 皮膚科 受診メモ

【症状】
・出た場所：＿＿＿＿＿＿（例：まぶた、ほお、首）
・いつから：〇年〇月ごろ
・どんな症状：赤み／かゆみ／ぶつぶつ／皮むけ／はれ
・くり返す時期：＿＿＿＿＿＿（例：化粧品を替えたあと）

【怪しい物】
・＿＿＿＿＿＿（使い始めて＿＿日後に症状）
・＿＿＿＿＿＿（使い始めて＿＿日後に症状）

【仕事】
・職業：＿＿＿＿＿＿　仕事で触れる物：＿＿＿＿＿＿

【今の薬】
・お薬手帳のとおり／ほかに：＿＿＿＿＿＿

【初診で聞くこと】
□ 持ってきた化粧品も貼れますか
□ 検査中の仕事や入浴は、どうすればよいですか
□ 今の薬は、検査の前に止める必要がありますか

【結果の日に聞くこと】
□ 反応が出た成分は、化粧品の表示で何と書かれますか
□ その成分は、どんな製品に入っていますか
□ 一緒に避けたほうがよい成分はありますか
□ 結果を紙でもらえますか
```

```
＜わたしが避ける成分＞

　入っていることが多い物：＿＿＿＿＿＿（例：ヘアカラー剤）
2. ＿＿＿＿＿＿（化粧品の表示名：＿＿＿＿＿＿）
　入っていることが多い物：＿＿＿＿＿＿
3. ＿＿＿＿＿＿（化粧品の表示名：＿＿＿＿＿＿）
　入っていることが多い物：＿＿＿＿＿＿

美容室・サロンの方へ
上の成分でかぶれます。施術の前に、使う薬剤の成分を確認させてください。
```

## 終わったかどうかの確認方法

結果をもらってから3か月後に、次の3つを確かめます。

1. 家にある化粧品と日用品すべてについて、カードの成分が入っていないか確かめ終えている
2. この3か月、同じ場所に同じ症状が出ていない
3. 通っている美容室やサロンに、カードの内容を伝えた

3つとも当てはまれば、検査の結果を生かせています。症状がまた出た場合は、そのとき使った物を書式1に書き足し、同じ皮膚科で相談します。
