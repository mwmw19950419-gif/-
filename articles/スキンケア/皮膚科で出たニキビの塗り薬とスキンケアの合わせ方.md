# 皮膚科で出たニキビの塗り薬とスキンケアの合わせ方　塗る順番・刺激が出たとき・化粧品を続けたいときの手順

## 今、こんな場面で止まっていませんか

皮膚科でニキビの塗り薬をもらった。説明は診察室で一度聞いただけで、家に帰ると、化粧水の前か後か思い出せない。塗り始めて数日で、顔が赤くヒリヒリしてきた。続けていいのか、やめるべきか。今の化粧品はそのまま使えるのか。この記事は、薬を続けながら肌を落ち着かせ、次の受診で相談するところまで進めます。

## この記事が向いていない人

- まだ皮膚科を受診していない人。この記事は、処方された薬がある人に向けて書いています。
- 飲み薬だけを出された人。この記事は塗り薬の使い方を扱います。
- 妊娠中の人、妊娠を予定している人。妊娠中に使えない塗り薬があります【要確認：アダパレンは妊婦には使用しないとされる】。処方した医師にすぐ伝えてください。

## 全体像：5ステップで、薬を続けられる形に整えます

ニキビの塗り薬は、塗ってすぐ効くものではありません。効果が見えるまでに数週間から数か月かかります【要確認：薬の種類で違う】。この記事は、途中でやめずに続けられる形を作ることを目指します。

1. もらった薬の種類と、医師の指示を確かめる
2. 朝と夜の塗る順番を決める
3. 今の化粧品を、続ける物と休む物に分ける
4. 刺激が出たときの対処を決めておく
5. 記録をつけて、次の受診で相談する

| ステップ | かかる時間 | 手元に用意する物 |
|---|---|---|
| 1 | 10分 | 薬袋、薬の説明書、お薬手帳 |
| 2 | 15分 | 塗り薬、今の化粧品 |
| 3 | 15分 | 持っている化粧品すべて |
| 4 | 10分 | この記事の対処表 |
| 5 | 毎晩1分 | 記録表、スマホ |

迷いやすいのはステップ2です。塗る順番は、薬の種類と医師の考え方で変わります。インターネットで調べると、正反対の説明が両方見つかります。この記事では、どちらの指示を受けた場合でも迷わないよう、2つの順番を並べて説明します。

### この先の有料部分に入っているもの

- 状況別の進め方（刺激が出た／保湿剤も一緒に出された／今の化粧品を続けたい）
- ステップ1〜5の手順。薬袋のどこを見るか、朝と夜の塗る順番の具体例
- 赤み、衣類の色落ち、塗る量など、つまずきやすい5か所と対処
- そのまま使える書式3つ（朝と夜の塗る順番の表／副作用の記録表／次の受診で聞くことのリスト）
- 4週間後に、薬を続けられる形ができたかを確かめる方法

ーーー ここから有料 ーーー

## 状況の分かれ方：あなたはA・B・Cのどれですか

### A 塗り始めて、赤みやヒリヒリが出た

ニキビの塗り薬の中には、使い始めの2週間ほどに、乾燥、赤み、ヒリヒリ、皮むけが出やすいものがあります【要確認：アダパレン、過酸化ベンゾイルなどで多いとされる】。多くは続けるうちに落ち着きます。ただし、我慢してよい程度かは自分で決めません。先に、つまずきやすい箇所の1にある「すぐ連絡する目安」に当てはまるかを見ます。当てはまらなければ、ステップ4の対処で様子を見ます。

### B 保湿剤も一緒に出された

ヘパリン類似物質（「ヒルドイド」などの名前で出る保湿剤）などが一緒に出た人です【要確認：処方される保湿剤の種類】。保湿剤が薬の前か後かを、薬袋や説明書で確かめます。書かれていなければ、薬局に電話して聞きます。その答えを、ステップ2で使います。

### C 今使っている化粧品を続けたい

化粧品をすべてやめる必要はありません。ただし、薬と似た働きを持つ化粧品を重ねると、刺激が強く出ることがあります。ステップ3で、続ける物と休む物に分けます。

## ステップ1 もらった薬の種類と、医師の指示を確かめる

薬袋か、薬局でもらった「薬の説明書」（薬剤情報提供書）を見ます。確かめるのは次の4つです。

- 薬の名前：例）ディフェリンゲル0.1%、ベピオゲル2.5%、エピデュオゲル、デュアック配合ゲル
- 1日に塗る回数：例）1日1回
- 塗る時間：例）就寝前、洗顔後
- 塗る範囲：例）ニキビの部分だけ／ニキビができやすい範囲全体

塗る範囲は見落としやすい項目です。アダパレン（ディフェリンゲルの成分）などは、ニキビ1つずつではなく、できやすい範囲全体に薄く塗るよう指示されることがあります【要確認：医師の指示に従う】。

説明書に書いていないことは、お薬手帳アプリのメモ欄か、紙のお薬手帳に「確認すること」として書いておきます。薬局の電話番号は、薬袋の下の欄に書かれています。

## ステップ2 朝と夜の塗る順番を決める

医師の指示は、大きく2つに分かれます【要確認：処方した医師の指示が優先】。

- **パターン1 保湿してから薬を塗る**（刺激をやわらげたいとき）
  夜：洗顔 → 化粧水 → 保湿剤 → 5分待つ → 塗り薬
- **パターン2 薬を塗ってから保湿する**（薬を肌に直接届けたいとき）
  夜：洗顔 → 塗り薬 → 5〜10分待つ → 化粧水 → 保湿剤

どちらの指示も受けていない場合は、薬局に電話して「ニキビの塗り薬と保湿の順番を確認したい」と伝えます。薬の名前を聞かれるので、薬袋を手元に置きます。

夜に塗る薬なら、朝は薬を使いません。朝は、洗顔 → 化粧水 → 保湿剤 → 日焼け止め、の順です。日光に肌が敏感になる薬もあるため、日焼け止めは毎朝塗ります【要確認：薬の種類による】。

量の目安：顔全体に塗る指示なら、人差し指の先に米粒2〜3つ分を出し、額・両ほお・鼻・あごの5か所に置いてから広げます【要確認：量は医師の指示による】。

決めた順番は、書式1の表に書いて洗面所に貼ります。

## ステップ3 今の化粧品を、続ける物と休む物に分ける

持っている化粧品を全部並べ、パッケージ裏の「全成分」の欄を見ます。次の成分が入った物は、薬に慣れるまでの最初の4週間は休みます【要確認：医師に確かめることを勧める】。

- レチノールなどのビタミンAの仲間
- グリコール酸などのピーリング成分
- 高い濃度のビタミンC
- スクラブ入りの洗顔料

成分表示でどんな名前で書かれるかは、別記事「レチノールやピーリングなど刺激の強い成分の始め方」の無料部分（全体像）に一覧があります。

洗顔料（スクラブなし）、化粧水、乳液、クリーム、日焼け止めは続けてかまいません。新しい化粧品は、薬に慣れるまで増やしません。

例）手持ちが「洗顔フォーム、化粧水、ビタミンC美容液、乳液、日焼け止め、ピーリングジェル」なら、休むのはビタミンC美容液とピーリングジェルの2つです。

## ステップ4 刺激が出たときの対処を決めておく

刺激の強さで、やることを3段階に分けておきます【要確認：医師から別の指示がある場合はそちらに従う】。

| 肌の状態 | やること |
|---|---|
| 少しつっぱる、かさつく | 保湿剤の量を増やす。薬はそのまま |
| 赤みとヒリヒリが3日以上続く | 薬を1日おきにしてよいか、薬局か医院に電話で確かめる |
| 腫れる、強く痛む、水ぶくれ | 薬をやめ、処方した医院に連絡する |

電話では「〇月〇日にニキビの塗り薬をもらった〇〇です。塗り始めて〇日目で、赤みとヒリヒリがあります。続けてよいか確かめたいです」と伝えます。

## ステップ5 記録をつけて、次の受診で相談する

毎晩、書式2の記録表に1行だけ書きます。書くのは、薬を塗ったか、刺激の強さ（0〜3の4段階）、新しいニキビの数の3つです。週に1回、同じ場所・同じ明るさで顔の写真を撮ります。

例）「11/5　塗った　刺激2　新しいニキビ1個」

受診の前日に、書式3のリストへ聞きたいことを書き込みます。記録表と写真を見せると、医師は薬の量や回数を変えるかを判断しやすくなります。

## つまずきやすい箇所と、その対処

1. **刺激が強いのに我慢して塗り続ける**：腫れ、強い痛み、水ぶくれ、目のまわりまで広がる赤みは、すぐ連絡する目安です。薬をやめて医院に電話します【要確認】。
2. **タオルや枕カバーの色が抜けた**：過酸化ベンゾイルを含む薬（ベピオゲル、エピデュオゲル、デュアック配合ゲルなど）は、布や髪の色を抜くことがあります【要確認】。白いタオルと枕カバーに替えます。髪の生え際に塗るときは、髪に付かないようにします。
3. **塗る量が多すぎる**：多く塗っても効果は上がらず、刺激が強くなります。ステップ2の量の目安を守ります。
4. **目や口のまわり、小鼻のわきまで塗る**：皮膚が薄く、刺激が出やすい場所です【要確認】。この3か所は避けるよう指示されることが多いので、医師に確かめます。
5. **2週間で効かないとやめてしまう**：効果が見えるまでには時間がかかります。自分でやめる前に、記録表を持って受診し、続けるかを医師と決めます。

## そのまま使える書式3つ

### 書式1 朝と夜の塗る順番の表（洗面所に貼る）

```
ニキビの塗り薬　塗る順番（令和〇年〇月〇日から）

薬の名前：＿＿＿＿＿＿＿＿　1日＿＿回
塗る範囲：ニキビの部分だけ ／ できやすい範囲全体

【夜】
□ 1. 洗顔（スクラブなし）
□ 2. ＿＿＿＿＿＿（例：化粧水）
□ 3. ＿＿＿＿＿＿（例：保湿剤）
□ 4. ＿＿分待つ
□ 5. ＿＿＿＿＿＿（例：塗り薬　米粒＿＿つ分）
□ 6. ＿＿＿＿＿＿

【朝】
□ 1. 洗顔
□ 2. 化粧水
□ 3. 保湿剤
□ 4. 日焼け止め

休む化粧品：＿＿＿＿＿＿、＿＿＿＿＿＿（〇月〇日まで）
薬局の電話：＿＿＿-＿＿＿＿-＿＿＿＿
```

〇/〇 ｜ ○・× ｜ ＿＿ ｜ ＿＿個 ｜ ＿＿＿＿＿＿

### 書式3 次の受診で聞くことのリスト

```
〇月〇日 受診メモ

薬：＿＿＿＿＿＿　使い始めた日：〇月〇日（今日で＿＿日目）

今の状態
・刺激：最初の2週間は＿＿。今は＿＿
・ニキビ：新しくできる数は、週に＿＿個くらい
・薬を休んだ日：＿＿日（理由：＿＿＿＿＿＿）

聞きたいこと
□ このまま続けてよいですか
□ 保湿と薬は、どちらを先に塗ればよいですか
□ 休んでいる化粧品（＿＿＿＿＿＿）は、いつから使えますか
□ 生理前や季節で悪くなるときは、どうすればよいですか
□ 次の受診はいつですか

（記録表と写真を見せる）
```

## 終わったかどうかの確認方法

薬を使い始めて4週間たったら、次の4つを確かめます。

1. 書式2の記録表で、刺激の強さが2以上の日が、最近1週間で1日以下になっている
2. 週1回の写真で、新しくできるニキビの数が、使い始めの週より減っているか、同じくらい
3. 塗る順番の表を見なくても、朝と夜のケアができる
4. 次の受診日が決まっていて、書式3のリストを書き終えている

4つとも当てはまれば、薬を続けられる形ができています。ニキビが増えている場合や、刺激が続いている場合は、次の受診日を待たずに医院へ相談します。
