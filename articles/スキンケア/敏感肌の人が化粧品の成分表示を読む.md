# 敏感肌の人が化粧品の成分表示を読む　避けたい成分を、店頭と通販で見つける手順

## 今、こんな場面で止まっていませんか

化粧品で荒れたことがあり、合わない成分を避けたい。でも、パッケージ裏の成分表示はカタカナが30個以上並んでいて、どれが何か分からない。「アルコールフリー」と書いてあるのに荒れたこともある。店で裏面を見ても判断できず、買えずに帰ってくる。この記事は、避けたい成分を決め、店頭と通販の両方で探し出せるようになるまで進めます。

## この記事が向いていない人

- 病院の薬や、薬局で買う医薬品の成分を調べたい人。表示の決まりが違います。
- 成分の良し悪しや効果を知りたい人。この記事は「避けたい成分を見つける」ための読み方だけを扱います。
- 何に反応しているのか、まったく見当がつかない人。皮膚科のパッチテストで避ける成分を決めてから読むと、この記事の手順が生きます。

## 全体像：5ステップで、避けたい成分を探せるようになります

化粧品の成分表示には、決まりがあります。これを知っておくと、裏面のどこを見ればいいかが分かります。

- 化粧品は、配合したすべての成分を表示する決まりがあります（全成分表示）
- 原則として、配合量の多い順に並びます
- 配合量が1%以下の成分と、色をつける成分（着色剤）は、順番を問わずに並べてよいことになっています
- 「薬用」と書かれた医薬部外品は決まりが違います。並び方が配合量の順とは限らないので、最後の行まで読みます

つまり、避けたい成分は「どこに書かれていても見つける」必要があります。最初の数行だけを見ても、見落とします。

1. 避けたい成分を決める
2. 成分の表示名と、別名を調べる
3. 店頭で、裏面の全成分を読む
4. 通販で、商品ページの全成分を探す
5. 分からない成分は、メーカーに問い合わせる

| ステップ | かかる時間 | 使う物 |
|---|---|---|
| 1・2 | 最初に1時間 | 荒れた化粧品の箱、パッチテストの結果 |
| 3 | 1商品3分 | スマホのカメラ |
| 4 | 1商品2分 | スマホのブラウザの「ページ内検索」 |
| 5 | 返事まで数日 | メーカーの問い合わせ窓口 |

### この先の有料部分に入っているもの

- 状況別の進め方（アルコールで荒れる／香料で荒れる／パッチテストで成分が分かっている）
- ステップ1〜5の手順。荒れた化粧品から共通の成分を探す方法、店頭でのカメラの使い方、通販のページ内検索のやり方
- 「無添加」の表示、海外の化粧品の英語表記など、つまずきやすい5か所と対処
- そのまま使える書式3つ（成分のチェックリスト／成分の別名リスト／メーカーへの成分の問い合わせ文）
- 1人で探せるようになったかを確かめる方法

## 状況の分かれ方：あなたはA・B・Cのどれですか

### A アルコールで荒れる

ここで言うアルコールは、主に「エタノール」です。表示では「エタノール」と書かれます。「アルコールフリー」が何を入れていないという意味かは、商品によって違います。気になるときは、ステップ5でメーカーに聞きます。

名前に似た字が入っていても、エタノールとは別の成分もあります。例）「セタノール」「ステアリルアルコール」「BG」（ブチレングリコール）は、エタノールとは別の成分です。これらで荒れるかどうかは、エタノールとは別に確かめます。

### B 香料で荒れる

香りをつける成分は、多くの場合「香料」の一語で表示されます。「無香料」は、香りをつける目的の香料を入れていないという意味です。ただし、植物から取った油（精油）は、「ラベンダー油」「オレンジ果皮油」などの名前で書かれ、香りがすることがあります。香料で荒れる人は、「〇〇油」「〇〇花油」も確かめます。

### C パッチテストで成分が分かっている

皮膚科の検査で、反応した成分の名前が分かっている人です。検査の名前と、化粧品の表示名が違うことがあります。ステップ2で、表示名に置きかえます。検査の受け方は、別記事「化粧品アレルギーの原因を皮膚科のパッチテストで調べる」で扱っています。

## ステップ1 避けたい成分を決める

荒れた化粧品の箱か容器を、できるだけ集めます。2つ以上あれば、共通して入っている成分を探します。

手順：
1. 荒れた化粧品の全成分を、スマホで撮影する
2. 書式1のチェックリストに、1つ目の全成分を書き写す
3. 2つ目の全成分と見比べ、両方に入っている成分に印をつける
4. 印がついた成分のうち、荒れなかった化粧品には入っていない物を、「避けたい成分の候補」にする

例）荒れた化粧水と乳液の両方に「エタノール」と「香料」があり、荒れなかったクリームにはどちらもない。→ 候補は「エタノール」と「香料」。

この方法で分かるのは、あくまで候補です。原因を確かめるには、皮膚科の検査が必要です。

## ステップ2 成分の表示名と、別名を調べる

成分には、化粧品の表示に使う名前（表示名称）が決まっています。日本化粧品工業会が「成分表示名称リスト」を公開しています。ホームページの検索欄に成分名を入れて調べます。

調べた結果は、書式2の別名リストにまとめます。書くのは次の3つです。

- 日本語の表示名：例）エタノール
- 英語の表示名（海外の化粧品で使われる）：例）Alcohol、Alcohol Denat.
- 名前が似ているが別の成分：例）セタノール

## ステップ3 店頭で、裏面の全成分を読む

1. 箱の裏、または容器の裏の「全成分」の見出しを探す
2. 文字が小さい場合は、スマホのカメラで撮影し、2本の指で広げて拡大する
3. 書式2の別名リストの成分を、最初の行から最後の行まで探す。1%以下の成分や着色剤は並び順が決まっていないので、最後まで読む

文字を探す時間を減らしたい場合は、カメラの文字認識を使います。iPhoneでは、カメラを成分表示に向けると文字を読み取ってコピーできる機能（テキスト認識表示）があります。機種や設定によって使えないこともあります。Androidでは「Googleレンズ」のテキストの機能で、同じことができます。コピーした文字をメモアプリに貼り、メモアプリの検索で「香料」などを探します。

箱がない試供品は、その場で店員に「全成分の表示を見せてください」と頼みます。

## ステップ4 通販で、商品ページの全成分を探す

1. 商品ページの「商品詳細」「成分」「全成分」などの項目を開く
2. ブラウザの「ページ内検索」で、避けたい成分の名前を入れる
   - iPhoneのSafari：共有ボタンのメニューにある「ページを検索」
   - AndroidのChrome：右上のメニュー「︙」にある「ページ内検索」
   - メニューの名前は、アプリの版によって少し違うことがあります
3. 見つからなかった場合も、全成分の項目自体が載っているかを目で確かめる。載っていない商品は、ステップ5で問い合わせるか、買うのを見送る

例）「エタノール」で検索して0件、「香料」で検索して0件、全成分の項目はある。→ 候補から外れているので、ステップ2の別名も検索してから判断します。

## ステップ5 分からない成分は、メーカーに問い合わせる

表示を見ても判断できないときは、メーカーに聞きます。メーカーのホームページの「お問い合わせ」から、書式3の文面で送ります。返事が来るまでは買いません。

聞けることの例：
- 「無香料」の商品に、香りのする成分が入っているか
- 「アルコールフリー」が、何を入れていないという意味か
- リニューアルで成分が変わったか

## つまずきやすい箇所と、その対処

1. **「無添加」と書いてあれば安心だと思う**：「何を」入れていないかは、商品ごとに違います。箱やホームページで「〇〇無添加」の〇〇を確かめます。
2. **表示名の一部だけが違う**：例）「ラウリル硫酸Na」と「ラウリル硫酸ナトリウム」は同じ成分です。書式2に、略した書き方も足しておきます。
3. **海外の化粧品で、表示が英語だけ**：書式2の英語の表示名で探します。日本で正規に売られている物には、日本語の表示が貼られていることもあります。
4. **同じ商品なのに、前と違う成分が入っている**：リニューアルで成分が変わることがあります。買い直すたびに、全成分を見直します。
5. **成分が分かっても、また荒れる**：避けたい成分の候補が合っていない可能性があります。荒れた物を書式1に足して見比べ直すか、皮膚科で検査を受けます。

## そのまま使える書式3つ

### 書式1 成分のチェックリスト

```
成分のチェックリスト（〇年〇月〇日）

商品A：＿＿＿＿＿＿（荒れた ／ 荒れなかった）
商品B：＿＿＿＿＿＿（荒れた ／ 荒れなかった）
商品C：＿＿＿＿＿＿（荒れた ／ 荒れなかった）

成分名 ｜ A ｜ B ｜ C ｜ 荒れた物すべてにある
＿＿＿＿＿＿ ｜ ○ ｜ ○ ｜ － ｜ ★
＿＿＿＿＿＿ ｜ ○ ｜ － ｜ ○ ｜
＿＿＿＿＿＿ ｜ － ｜ ○ ｜ － ｜
（全成分を1行ずつ書く）

★のうち、荒れなかった物に入っていない成分
→ 避けたい成分の候補：＿＿＿＿＿＿、＿＿＿＿＿＿
```

### 書式2 成分の別名リスト

```
避けたい成分の別名リスト（スマホに保存）

1. 日本語の表示名：＿＿＿＿＿＿
　 略した書き方：＿＿＿＿＿＿
　 英語の表示名：＿＿＿＿＿＿
　 似ているが別の成分（避けなくてよい）：＿＿＿＿＿＿

2. 日本語の表示名：＿＿＿＿＿＿
　 略した書き方：＿＿＿＿＿＿
　 英語の表示名：＿＿＿＿＿＿
　 似ているが別の成分（避けなくてよい）：＿＿＿＿＿＿

3. 日本語の表示名：＿＿＿＿＿＿
　 略した書き方：＿＿＿＿＿＿
　 英語の表示名：＿＿＿＿＿＿
　 似ているが別の成分（避けなくてよい）：＿＿＿＿＿＿

確かめた日：〇年〇月〇日（根拠：パッチテスト ／ 自分の記録）
```

### 書式3 メーカーへの成分の問い合わせ文

```
件名：〇〇（商品名）の成分についてのお問い合わせ

〇〇株式会社 お客様相談室 ご担当者様

いつもお世話になっております。
肌が敏感で、次の成分で荒れたことがあるため、購入前に確認させてください。

・避けたい成分：＿＿＿＿＿＿、＿＿＿＿＿＿
・お問い合わせの商品：＿＿＿＿＿＿（容量：＿＿ml）

お聞きしたいこと
1. 上記の成分は、この商品に配合されていますか
2. 「〇〇フリー」「〇〇無添加」の表示は、何を配合していないという意味ですか
3. 最近、成分の変更（リニューアル）はありましたか

お忙しいところ恐れ入りますが、ご回答をお願いいたします。

〇〇〇〇（氏名）
メールアドレス：＿＿＿＿＿＿
```

## 終わったかどうかの確認方法

次の4つがそろえば、1人で避けたい成分を探せる状態です。

1. 書式2の別名リストがスマホに保存され、すぐ開ける
2. 店頭で1商品の全成分を、3分以内に最後の行まで確かめられる
3. 通販のページ内検索で、避けたい成分の有無を確かめられる
4. 新しく選んだ化粧品を2週間使い、荒れていない

荒れた場合は、その商品を書式1に足して、避けたい成分の候補を見直します。
