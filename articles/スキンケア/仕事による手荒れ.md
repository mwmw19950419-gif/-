# 仕事による手荒れ　家事・職場の薬剤や消毒・手湿疹の治療中、3つの場合のケアと職場への相談

## 今、こんな場面で止まっていませんか

毎日の水仕事や、職場での手洗いと消毒で、手が荒れて切れてきた。ハンドクリームを塗っても、すぐまた洗うので追いつかない。指先が割れて痛み、仕事に差し支える。職場に手袋や保湿剤を頼みたいが、言い出しにくい。この記事は、手荒れの原因を絞り、1日のケアの決まりを作り、職場に相談するところまで進めます。

## この記事が向いていない人

- 手に水ぶくれが広がる、膿が出る、急に腫れたなどの症状がある人。先に皮膚科を受診してください。
- ゴム手袋をつけると、すぐにかゆみやじんましんが出る人。天然ゴム（ラテックス）のアレルギーの可能性があります【要確認】。皮膚科で相談します。
- 手以外にも湿疹が広がっている人。手だけのケアでは足りないことがあります。

## 全体像：5ステップで、荒れにくい1日の決まりを作ります

手荒れは、水、洗剤、消毒液、薬剤によって、皮膚の表面の油分や水分が奪われて起こります。仕事の手順そのものを変えずに、荒れる回数を減らすのがこの記事のやり方です。

1. 手荒れの原因を書き出す
2. 手洗い・消毒・保湿の1日の決まりを作る
3. 手袋の使い方を決める
4. 職場に相談する
5. 治らなければ皮膚科へ行く（治療中の人は医師と決める）

1日の中で、手荒れに関わる場面は次の4つです。

| 場面 | 例 | 決めること |
|---|---|---|
| 手を洗う | 1日20回 | 湯の温度、拭き方 |
| 消毒する | 入室のたびにアルコール | 手洗いとの使い分け |
| 水や薬剤に触れる | 洗い物、カラー剤、清掃 | 手袋の種類と重ね方 |
| 保湿する | 休憩のとき | 塗るタイミングと量 |

ステップ1で、この4つの場面が自分の1日に何回あるかを数えます。回数が分かると、どこから変えれば効くかが見えます。

### この先の有料部分に入っているもの

- 状況別の進め方（家事が原因／仕事で薬剤や消毒に触れる／手湿疹で治療中）
- ステップ1〜5の手順。手洗いと保湿の決まり、手袋の重ね方、職場で頼めることの例
- 消毒がしみる、クリームで書類が汚れるなど、つまずきやすい5か所と対処
- そのまま使える書式3つ（手袋と保湿のルール表／職場への配慮の相談文／皮膚科で伝えるメモ）
- 手荒れの決まりが効いているかを、4週間後に確かめる方法

## 状況の分かれ方：あなたはA・B・Cのどれですか

### A 家事が原因

食器洗い、洗濯、子どもの世話などで、1日に何度も水に触れる人です。主婦湿疹（家事による手湿疹）と呼ばれることがあります。家族に家事の一部を分けられるかも、ステップ1で考えます。

### B 仕事で薬剤や消毒に触れる

美容師のシャンプーやカラー剤、医療や介護の手洗いと消毒、飲食店の洗い物、清掃の洗剤などに触れる人です。仕事で触れる物が原因の皮膚炎は、労災保険（仕事が原因のけがや病気を補償する国の保険）の対象になることがあります【要確認】。職場への相談（ステップ4）で、手袋や作業の分け方を頼みます。

### C 手湿疹で治療している

皮膚科で塗り薬が出ている人です。塗り薬は、洗うと落ちてしまいます。薬を塗る時間を、手を洗う回数が少ない時間に合わせます。ステップ5で、医師と塗る時間を決めます。

## ステップ1 手荒れの原因を書き出す

ある1日、手が水や薬剤に触れた回数を数えます。スマホのメモに「正」の字で記録します。

- 手を洗った回数
- アルコール消毒をした回数
- 水仕事の時間（合計）
- 触れた洗剤や薬剤の名前

例）
- 手洗い：22回
- 消毒：15回
- 水仕事：合計1時間半（洗い物）
- 触れた物：食器用洗剤、塩素系の漂白剤

同じ記録を、仕事の日と休みの日で1日ずつ取ると、原因の見当がつきやすくなります。例）仕事の日は手洗い22回・消毒15回、休みの日は手洗い8回・消毒0回で、休みの日の翌日は痛みが軽い。→ 職場での手洗いと消毒が主な原因と考え、ステップ2とステップ4を優先します。

荒れがひどい指や場所も書きます。例）右手の人差し指と中指の先、指の間。いつも同じ場所なら、その指が触れている物が原因の候補です。

## ステップ2 手洗い・消毒・保湿の1日の決まりを作る

**手を洗うとき**
- 湯はぬるま湯にする。熱い湯は油分を多く奪います
- 石けんは手のひらで泡立ててから使い、すすぎは十分にする
- 拭くときは、ペーパータオルで押さえるように水気を取る。こすらない
- 拭いたら1分以内に、保湿剤を少量塗る

**消毒するとき**
- 手に目に見える汚れがなければ、職場の決まりの範囲でアルコール消毒を使う。アルコール消毒は、石けんでの手洗いより手荒れが少ないとする考え方があります【要確認：職場の感染対策の決まりを優先】
- 傷があってしみる場合は、ステップ4で職場に相談する

**保湿するとき**
- 日中：少量を、手洗いのあと毎回。ベタつかない物を選ぶ
- 夜：寝る前に多めに塗り、綿の手袋をして寝る

決めたことは、書式1のルール表に書き、職場のロッカーや台所に貼ります。

## ステップ3 手袋の使い方を決める

- **水仕事**：綿の手袋の上に、ゴムかビニールの手袋を重ねます。綿の手袋が汗を吸い、蒸れを防ぎます
- **長時間つける**：1時間に1回は外して、中の汗を拭きます。綿の手袋が湿ったら替えます
- **薬剤に触れる仕事**：薬剤に合った手袋を選びます。例）美容師のカラー剤には、ニトリル（合成ゴム）の手袋【要確認：薬剤ごとの手袋の選び方】
- **ゴムで荒れる人**：ゴムを使わない手袋（ニトリル、ビニール）に替えます。パウダーなしの物を選びます

例）台所に「綿手袋＋ビニール手袋」を置き、洗い物のときは必ず両方つける。

## ステップ4 職場に相談する

Bの人は、1人の工夫では限界があります。上司か、衛生の担当者に相談します。産業医（会社と契約して社員の健康を見る医師）がいる職場では、産業医との面談を申し込む方法もあります。

頼めることの例です。

- 手袋の支給、または種類の変更
- 手洗い場への保湿剤の設置
- 手荒れが治るまで、水仕事や薬剤に触れる作業を減らしてもらう
- 休憩のときに、保湿する時間を取る

例）飲食店の洗い場で働く人なら「洗い物の時間に使う手袋を、今のゴム手袋から、綿の手袋と重ねて使えるビニール手袋に替えてほしい」「手洗い場に保湿剤を1本置いてほしい」のように、物と場所を具体的に頼みます。

相談は、書式2の文面でメールか書面にします。口頭だけだと、担当者が替わったときに伝わりません。皮膚科で診断書をもらえば、相談の裏づけになります。

## ステップ5 治らなければ皮膚科へ行く

ステップ2〜4を2週間続けても良くならない場合は、皮膚科を受診します。次の症状があるときは、2週間を待たずに受診します。

- 割れて血が出る
- 水ぶくれやぶつぶつが出る
- かゆみで眠れない

受診のときは、書式3のメモと、ステップ1の記録を持っていきます。仕事で触れる物が怪しい場合、その物で荒れているかを調べる検査（パッチテスト）を勧められることがあります。

Cの人は、塗り薬を塗る時間を医師と決めます。例）「寝る前に塗り、綿の手袋をする」「昼休みに1回塗る」。

## つまずきやすい箇所と、その対処

1. **アルコール消毒がしみる**：傷があるとしみます。しみる間は、職場の決まりの範囲で別の消毒方法があるか、衛生の担当者に聞きます。
2. **ハンドクリームで書類や商品が汚れる**：日中はベタつかないローションやジェルの保湿剤にし、夜に多めに塗ります。塗ったあと30秒ほど手をこすり合わせてなじませます。
3. **手袋の中が蒸れて悪化する**：綿の手袋を下につけ、湿ったら替えます。長い作業は途中で外して汗を拭きます。
4. **治ったら元のやり方に戻して、また荒れる**：手荒れは、原因が続くとくり返しやすくなります。治ったあとも、書式1のルールは続けます。
5. **職場に言い出せない**：書式2の文面を使うと、伝える内容が整理されます。皮膚科の診断書があると、相談が通りやすくなります。

## そのまま使える書式3つ

### 書式1 手袋と保湿のルール表

```
手荒れを防ぐルール（〇年〇月〇日から）

【手を洗うとき】
□ ぬるま湯で洗う
□ 石けんは泡立ててから
□ ペーパーで押さえて拭く
□ 1分以内に保湿剤（＿＿＿＿＿＿）

【消毒するとき】
□ 汚れがなければ消毒（職場の決まりの範囲で）
□ しみるときは担当者に相談

【水や薬剤に触れるとき】
□ 下：綿の手袋　上：＿＿＿＿の手袋
□ 1時間ごとに外して汗を拭く

【夜】
□ 保湿剤を多めに塗る
□ 綿の手袋をして寝る
□ 塗り薬（＿＿＿＿＿＿）を指示どおりに
```

### 書式2 職場への配慮の相談文

```
件名：手荒れについてのご相談

〇〇課 〇〇様

お疲れさまです。〇〇課の〇〇です。
業務での手洗いや〇〇（例：洗剤・消毒液・カラー剤）の使用により、手荒れが続いています。
現在、指先が割れて痛みがあり、〇〇の作業に支障が出ています。

自分でも次のことを続けています。
・ぬるま湯で手を洗い、毎回保湿する
・水仕事では手袋を二重にする

そのうえで、次の点をご相談できますでしょうか。
1. 〇〇製の手袋の支給（または種類の変更）
2. 手洗い場への保湿剤の設置
3. 症状が落ち着くまで、〇〇の作業を減らしていただくこと

皮膚科を受診しており、必要であれば診断書を提出いたします。
ご検討をお願いいたします。

〇〇（氏名）
```

### 書式3 皮膚科で伝えるメモ

```
〇月〇日 皮膚科 受診メモ（手荒れ）

仕事：＿＿＿＿＿＿　家事：＿＿＿＿＿＿

1日に手が触れる物（記録した日：〇月〇日）
・手洗い：＿＿回　・消毒：＿＿回
・水仕事：合計＿＿時間
・触れる洗剤・薬剤：＿＿＿＿＿＿、＿＿＿＿＿＿
・手袋：＿＿＿＿（ゴム／ビニール／ニトリル）

症状
・いつから：〇年〇月ごろ
・場所：＿＿＿＿＿＿（例：右手の人差し指と中指の先）
・どんな症状：乾燥／割れ／赤み／かゆみ／水ぶくれ
・休みの日は：よくなる／変わらない

聞きたいこと
□ 仕事で触れる物が原因か、調べられますか
□ 塗り薬は、仕事中と寝る前のどちらに塗ればよいですか
□ 職場に出す診断書を書いていただけますか
```

## 終わったかどうかの確認方法

この記事の手順を始めて4週間後に、次の4つを確かめます。

1. 指の割れや出血が、最近1週間ない
2. 書式1のルール表のとおりに、毎日ケアできている
3. Bの人は、職場に相談し、返事をもらっている
4. 2週間以上良くならなかった人は、皮膚科を受診している

4つとも当てはまれば、荒れにくい1日の決まりができています。季節の変わり目や、仕事の内容が変わったときは、ステップ1の記録をもう一度取り直します。
