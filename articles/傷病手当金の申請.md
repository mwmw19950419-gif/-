# 傷病手当金の申請　休職中に給料の代わりを受け取るまでの全手順

## 今、こんな場面で止まっていませんか

医師に「しばらく休みましょう」と言われ、会社を休み始めた。給料が出ないと聞き、傷病手当金を知った。申請書を開くと、自分の欄、会社の欄、医師の欄に分かれている。誰に何を頼めばいいか分からない。退職も考えているが、辞めたら受け取れなくなるのかも分からない。この記事は、そこから1回目の入金までを進めます。

## この記事が向いていない人

- 国民健康保険（自営業やフリーランスが入る、市区町村の保険）に入っている人。国民健康保険には、原則としてこの制度がありません【要確認：独自に設けている自治体があるか】。
- 仕事中や通勤中のけが・病気で休んでいる人。こちらは労災保険（仕事が原因のけがや病気を補償する国の保険）の対象です。
- 出産で休む人。出産手当金という別の制度を使います。

## 全体像：5ステップで1回目の入金まで進みます

傷病手当金は、会社員が入る健康保険から出るお金です。病気やけがで働けず、給料が出ない日について、給料のおよそ3分の2が出ます。

1. 受け取れる条件に当てはまるか確かめる
2. 申請書を手に入れる
3. 自分の欄を書く
4. 医師の欄と会社の欄を頼む
5. 提出して、入金を確かめる

2回目からは、3〜5を1か月ごとにくり返します。1回目の入金までは、休み始めてから早くて1か月半ほどかかります【要確認：審査にかかる日数は保険者ごとに違う】。

各ステップで関わる相手と、かかる時間の目安です。

| ステップ | 関わる相手 | かかる時間の目安 |
|---|---|---|
| 1 条件を確かめる | 自分 | 10分 |
| 2 申請書を手に入れる | 自分（または会社の総務） | 30分 |
| 3 自分の欄を書く | 自分 | 30分〜1時間 |
| 4 医師の欄と会社の欄を頼む | 主治医、人事 | 1〜3週間 |
| 5 提出と入金の確認 | 健康保険 | 2〜4週間【要確認】 |

時間がかかるのはステップ4です。医師の欄は、申請する期間が終わってからでないと書いてもらえません。そのため1回目の申請は、休み始めて1か月たった頃の受診日が出発点になります。

今のうちに手元へ用意しておくものは3つです。健康保険証（または資格情報のお知らせ）、振込先にする自分名義の通帳、休み始めた日と有給休暇を使った日を書いたメモです。

### この先の有料部分に入っているもの

- 状況別の進め方（在職中／退職後も受け取る／休みが長引く）
- ステップ1〜5の手順。申請書の欄ごとの書き方と入力例
- 退職日に出勤してしまう、医師が書いてくれないなど、つまずきやすい5か所と対処
- そのまま使える文例3つ（人事への記入依頼メール／主治医への記入依頼メモ／休職中の月1回の近況報告メール）
- 申請が通ったかを確かめる方法と、入金額の目安の計算

## 状況の分かれ方：あなたはA・B・Cのどれですか

### A 会社に在籍したまま休んでいる

一番多い形です。会社の欄を、申請のたびに会社に書いてもらいます。会社によっては、申請書を会社から健康保険に出す決まりがあります。最初に人事へ「申請書は会社経由ですか、自分で郵送ですか」と聞いてください。

### B 休んだまま退職し、退職後も受け取る

退職後も受け取り続けられるのは、次の2つをどちらも満たす人です。

- 退職日までに、健康保険に続けて1年以上入っている
- 退職日に、傷病手当金を受け取っているか、受け取れる状態にある

退職日より後の期間だけを申請するときは、会社の欄は不要です【要確認：保険者によって扱いが違う】。申請書は自分で健康保険に郵送します。退職後の健康保険の切り替えは、別記事「退職するときの手続き一式」のステップ2で扱っています。

### C 休みが長引き、何か月も申請を続ける

受け取れる期間は、支給が始まった日から通算で1年6か月です。途中で出勤した日があれば、その分だけ後ろに延びます。申請は1か月ごとにまとめると、医師と会社への依頼が月1回の決まった作業になります。2週間ごとに申請すると入金は早まりますが、医師の記入料（文書料）が毎回かかります【要確認：文書料の額。保険が使えて3割負担で300円程度の例がある】。

## ステップ1 受け取れる条件に当てはまるか確かめる

条件は4つです。全部に当てはまれば対象になります。

1. 仕事以外の病気やけがで療養している
2. 医師が「働けない」と判断している
3. 連続して3日休み、4日目以降も休んでいる
4. 休んだ日に給料が出ていない、または出ていても傷病手当金より少ない

最初の連続3日を「待期」と呼びます。待期の3日分は支給されません。待期には、土日や有給休暇の日も数えられます。

入力例：12月1日（月）から休み始めた場合、12月1日〜3日が待期です。12月4日から支給の対象になります。

## ステップ2 申請書を手に入れる

健康保険証（またはマイナ保険証を使う人に届く「資格情報のお知らせ」）の「保険者名称」欄を見ます【要確認：資格情報のお知らせの欄名】。

- 「全国健康保険協会」とある人：協会けんぽです。協会けんぽのホームページで、トップページ →「申請書・届出書」→「傷病手当金」の順に進み、「健康保険 傷病手当金 支給申請書」のPDFを印刷します【要確認：メニュー名は時期により変わる】。
- 「〇〇健康保険組合」とある人：会社が入っている健康保険組合です。組合のホームページか、会社の総務で入手します。

協会けんぽの申請書は4枚1組です【要確認：現行様式の枚数と並び】。

- 1枚目・2枚目「被保険者記入用」：あなたが書く
- 3枚目「事業主記入用」：会社が書く
- 4枚目「療養担当者記入用」：医師が書く

## ステップ3 自分の欄を書く

1枚目・2枚目の主な欄と入力例です【要確認：欄の名前は様式改定で変わることがある】。

- 「被保険者証の記号・番号」：例）記号 12345678、番号 21
- 「申請期間（療養のために休んだ期間）」：例）令和8年12月1日から令和8年12月31日まで
- 「被保険者の仕事の内容」：休む前の仕事を具体的に書きます。例）営業事務。受注データの入力と電話対応
- 「傷病名」「発病・負傷年月日」：例）適応障害、令和8年11月20日
- 「振込先指定口座」：あなた名義の口座
- 報酬（給料）を受けたかを聞く欄：有給休暇を使った日があれば「はい」に印を付け、その日付を書きます

書き終えたら、スマホで全ページを撮影します。2回目からは、申請期間だけを変えて同じ内容を書けます。

## ステップ4 医師の欄と会社の欄を頼む

医師の欄は、申請期間が終わってから書いてもらいます。12月分なら、12月31日を過ぎてから最初の受診日に渡します。期間の途中では、医師は「この期間は働けなかった」と証明できないからです。

受診日に受付で「傷病手当金の申請書の記入をお願いします」と伝え、申請書と文例2のメモを渡します。その場で書いてもらえない病院では、受け取りが次の受診日になります。

会社の欄は、出勤した日と給料の支払いを書いてもらう欄です。文例1のメールで人事に頼みます。会社が書いたあと、健康保険に直接出すのか、あなたに返すのかを必ず聞いてください。

## ステップ5 提出して、入金を確かめる

4枚がそろったら、会社経由か郵送で提出します。協会けんぽに郵送する場合の宛先は、勤め先がある都道府県の協会けんぽ支部です【要確認：退職後は住所地の支部か】。

郵送の前に、次の3つを見直します。

- 4枚すべてに記入がある
- 申請期間の日付が、自分の欄・医師の欄・会社の欄で一致している
- 振込口座の名義があなた本人になっている

支給が決まると「支給決定通知書」が届きます【要確認：健康保険組合によっては通知を省く】。

## つまずきやすい箇所と、その対処

1. **退職日に出勤してしまう**：Bの人が、挨拶のつもりで退職日に出勤すると、その日は働けたと見なされます。退職後に受け取れなくなります【要確認：扱いは保険者の判断による】。退職日は欠勤か有給休暇にし、挨拶は前日までに済ませます。
2. **医師が「働けない」と書いてくれない**：通院の間が空くと、医師はその期間の状態を判断できません。月1回以上は受診し、この1か月の状態を文例2のメモで伝えます。
3. **有給休暇と重なる**：有給休暇を使った日は給料が出ているので、支給されません。有給休暇を残したい人は、待期の3日だけに使うと無駄が出ません。
4. **会社の記入に時間がかかる**：給料の締め日を過ぎないと書けない会社があります。申請期間を締め日に合わせます。例）締め日が毎月20日なら、申請期間を「11月21日〜12月20日」にする。
5. **申請を忘れていた**：申請できるのは、休んだ日ごとに、その翌日から2年以内です。2年以内なら、さかのぼってまとめて申請できます。

```
件名：傷病手当金申請書（事業主記入用）のご記入のお願い

〇〇部 〇〇様

お世話になっております。〇〇部の〇〇です。
療養のため休職しております。
傷病手当金の申請にあたり、申請書の「事業主記入用」のご記入をお願いいたします。

・申請期間：令和〇年〇月〇日〜令和〇年〇月〇日
・添付：傷病手当金支給申請書（被保険者記入用は記入済み）

あわせて、次の2点を教えてください。
1. ご記入後の申請書は、会社から提出いただけますか。私に返送いただく形ですか。
2. 次回以降も、同じ流れでお願いしてよろしいでしょうか。

お手数をおかけしますが、よろしくお願いいたします。

〇〇（氏名）
電話：〇〇〇-〇〇〇〇-〇〇〇〇
```

```

・申請期間：令和〇年〇月〇日〜令和〇年〇月〇日
・この期間の勤務：休職中で、一度も出勤していません
・この期間の状態：

　- 〇〇（例：電車に乗ると動悸がして、途中で降りました）

・傷病手当金：〇月分の申請書を〇月〇日にお送りします。事業主記入用のご記入をお願いいたします

〇〇（氏名）
```

## 終わったかどうかの確認方法

次の3つがそろえば、1回目の申請は完了です。

1. 振込口座に入金がある【要確認：通帳に印字される振込名義は保険者ごとに違う】
2. 入金額が、目安の計算とおおむね合っている
3. 支給決定通知書の「支給期間」が、申請した期間と一致している

入金額の目安は「休む前の月給（総支給額）÷30×3分の2×支給日数」で出します。例）月給30万円で、12月4日〜31日の28日分なら、30万円÷30×3分の2×28＝約18万6千円になります【要確認：実際は直近12か月の標準報酬月額（保険料計算のもとになる月給の区分）の平均で計算する】。

提出から1か月半たっても入金がない場合は、協会けんぽの支部か健康保険組合に電話します。「傷病手当金の審査状況を確認したい」と伝え、保険証の記号・番号と申請期間を答えます。
