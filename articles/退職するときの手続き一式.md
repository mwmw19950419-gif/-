# 退職するときの手続き一式　健康保険・年金・住民税・失業手当を期限内に終わらせる手順

## 今、こんな場面で止まっていませんか

退職日が決まり、人事から「保険証の返却」と「住民税をどうするか」を聞かれた。次の仕事までは1か月以上空く。健康保険は今のものを続けるのか、国民健康保険か、家族の扶養か。年金も切り替えが要るらしい。どれも期限があるのに、順番が分からない。この記事は、退職日の前後3週間でやることを、期限の早い順に片づけます。

## この記事が向いていない人

- 退職日の翌日に次の会社へ入る人。健康保険と年金は次の会社が手続きします。この記事で使うのはステップ4と6だけです。
- 定年退職で、年金を受け取り始める人。年金を受け取る手続きが別に必要です。
- 解雇の理由に納得できず、会社と争うつもりの人。先に、都道府県の労働局にある「総合労働相談コーナー」に相談してください。

## 全体像：6ステップで終わります

退職すると、会社が代わりにやっていた手続きを自分でやることになります。ステップは6つです。

1. 退職前に、会社から受け取る書類を確かめる
2. 健康保険を選んで加入する
3. 年金を国民年金に切り替える
4. 住民税の払い方を決める
5. ハローワークで失業手当の手続きをする
6. 次の会社に書類を出す

期限が短いのは2と3です。

- 今の健康保険を続ける場合：退職日の翌日から20日以内
- 国民健康保険と国民年金に入る場合：退職日の翌日から14日以内

この2つを先に済ませれば、残りは多少遅れても取り返せます。

時期ごとに並べると、次のようになります。

| 時期 | やること | ステップ |
|---|---|---|
| 退職日の2週間前まで | 人事に、受け取る書類と住民税の払い方を伝える | 1・4 |
| 退職日 | 保険証と社員証を返す | 1 |
| 退職日の翌日から14日以内 | 国民健康保険と国民年金に入る | 2・3 |
| 退職日の翌日から20日以内 | 今の健康保険を続ける場合は申し込む | 2 |
| 離職票が届いてから | ハローワークで失業手当の手続き | 5 |
| 次の会社の入社日 | 源泉徴収票などを出す | 6 |

どの状況の人でも、ステップ1の書類の確認と、ステップ4の住民税の払い方は必ず決めます。この2つは、退職日より前に人事とのやり取りで終わります。

退職日の翌日から新しい保険に入るまでの間に病院にかかった場合は、いったん全額を払います。加入したあとで、払いすぎた分の払い戻しを申請できます【要確認：払い戻しの申請先と期限】。

役所に行くのは1回にまとめられます。国民健康保険と国民年金の窓口は、多くの役所で同じ建物にあるからです。行く日には、ステップ1で受け取った書類と、本人確認書類とマイナンバーがわかる物を持っていきます。

### この先の有料部分に入っているもの

- 状況別の進め方（すぐ転職する／1か月以上空いて失業手当を受ける／家族の扶養に入る）
- ステップ1〜6の手順。窓口名、書類名、記入例つき
- 健康保険3つの選択肢の保険料を比べる計算手順
- 離職票が届かない、20日を過ぎたなど、つまずきやすい5か所と対処
- そのまま使える文例3つ（退職届／離職票の催促メール／家族の勤務先への扶養の依頼メール）
- 全部終わったかを確かめるチェック表

## 状況の分かれ方：あなたはA・B・Cのどれですか

### A 間を空けずに転職する

退職日から次の会社の入社日まで、空白が数日以内の人です。必要なのはステップ1・4・6です。

ただし空白の日が月末をまたぐと、その月の国民年金と国民健康保険が必要になります【要確認：月末退職か月の途中の退職かで扱いが変わる】。例）3月20日に退職し、4月1日に入社する場合、3月21日〜31日が空白です。この場合はステップ2・3も行います。

### B 1か月以上空いて、失業手当を受ける

ステップ1〜6をすべて行います。ステップ2の健康保険の選び方で、保険料の差が年に数万円になることがあります。計算してから選んでください。

### C 家族の扶養に入る

配偶者や親が会社員で、その健康保険の扶養に入る場合です。健康保険と年金の手続きは、家族の勤務先を通して行います。あなたが役所に行く必要はありません。家族の勤務先には届け出の期限があるので、退職日が決まったら文例3を家族に渡します【要確認：事業主の届出期限は事実発生から5日以内】。

注意点が1つあります。失業手当を受け取る間は、手当の日額によって扶養に入れません【要確認：日額3,612円以上で扶養の収入基準を超えるとする健康保険が多い】。その場合は、受け取る間だけBの手順で国民健康保険に入り、受け取り終えてから扶養に入ります。

## ステップ1 退職前に、会社から受け取る書類を確かめる

最後の出勤日までに、人事に次の5つの受け取り方を確認します。

| 書類 | 使う場面 | 受け取る時期の目安 |
|---|---|---|
| 離職票-1・離職票-2 | 失業手当（ステップ5） | 退職後10日前後に郵送 |
| 健康保険資格喪失証明書 | 国民健康保険への加入（ステップ2） | 頼まないと出ない会社がある |
| 源泉徴収票 | 次の会社の年末調整（ステップ6） | 退職後1か月以内 |
| 雇用保険被保険者証 | 次の会社（ステップ6） | 最終日か郵送 |
| 基礎年金番号がわかる書類 | 年金の切り替え（ステップ3） | 自分で持っていることが多い |

Bの人は、離職票が必要だと人事に必ず伝えます。転職先が決まっていると思い込み、離職票を出さない会社があります。

返す物は、健康保険証（持っている場合）、社員証、会社の備品です。

## ステップ2 健康保険を選んで加入する

選択肢は3つです。

- **任意継続**：今の会社の健康保険を、最長2年続ける。会社が払っていた分も自分で払うので、保険料は在職中のおよそ2倍になります。
- **国民健康保険**：住んでいる市区町村の保険。保険料は前の年の所得で決まります。
- **家族の扶養**：保険料はかかりません（Cの人）。

AとBの人は、次の手順で比べます。

1. **任意継続の保険料を出す**：給与明細の「健康保険料」を2倍にします。40歳以上の人は「介護保険料」も2倍にして足します。保険料には上限があり、協会けんぽは標準報酬月額（保険料計算のもとになる月給の区分）32万円が上限です【要確認：令和8年度の上限額】。例）健康保険料が15,000円なら、任意継続はおよそ月30,000円。
2. **国民健康保険の保険料を出す**：市区町村のホームページで「国民健康保険料 試算」と検索します。見つからなければ、役所の国民健康保険の窓口に電話し「退職予定です。保険料の概算を知りたい」と伝えます。前の年の源泉徴収票の「支払金額」を聞かれるので、手元に置いておきます。
3. **1年分の合計で比べ、安いほうを選ぶ**：会社都合の退職などで失業手当を受ける人は、国民健康保険料が大きく下がる場合があります【要確認：非自発的失業者の軽減。離職票の離職理由コードで判断される】。

加入の手続きは次のとおりです。

- **任意継続**：協会けんぽの場合、ホームページから「任意継続被保険者資格取得申出書」を印刷して書きます。「資格喪失年月日」欄には退職日の翌日を書きます。例）退職日が令和8年12月31日なら「令和9年1月1日」。住所地の協会けんぽ支部に郵送し、退職日の翌日から20日以内に届くようにします【要確認：必着か消印有効か】。
- **国民健康保険**：市区町村役所の国民健康保険の窓口で、加入の届け出をします。持ち物は、健康保険資格喪失証明書、本人確認書類、マイナンバーがわかる物です。届出書の「異動の理由」欄は「社会保険をやめた」に当たる項目を選びます【要確認：届出書の表記は自治体ごとに違う】。

## ステップ3 年金を国民年金に切り替える

会社員の間は厚生年金に入っていました。退職すると、国民年金の第1号被保険者（自分で保険料を払う人）に切り替えます。

国民健康保険と同じ日に、同じ役所の国民年金の窓口で済ませるのが早道です。窓口では「退職したので、国民年金の切り替えをお願いします」と伝えます。書類は「国民年金被保険者関係届書（申出書）」です【要確認：様式名と欄名】。マイナポータルからの電子申請にも対応しています【要確認：対応する手続きの範囲】。

持ち物は、基礎年金番号がわかる物（年金手帳か基礎年金番号通知書）、退職日がわかる書類（離職票か健康保険資格喪失証明書）、本人確認書類です。

保険料を払うのが難しい場合は、同じ窓口で「退職（失業）による特例免除」を申請できます。離職票か雇用保険受給資格者証のコピーを持っていきます。

Cの人で配偶者の扶養に入る場合は、第3号被保険者（配偶者の年金制度で保険料を負担しなくてよい人）になります。手続きは配偶者の勤務先が行います。

## ステップ4 住民税の払い方を決める

住民税は、前の年の所得に対する税金を、6月から翌年5月にかけて払う仕組みです。退職すると給料から引けなくなるので、残りの払い方を決めます。退職する月で分かれます。

- **1月〜5月に退職**：残りの分は、最後の給料か退職金から一括で引かれるのが原則です。
- **6月〜12月に退職**：「残りを最後の給料から一括で引いてもらう」か「自分で納付書で払う（普通徴収）」かを選べます。
- **すぐ次の会社に入る（Aの人）**：次の会社の給料から引き続き引いてもらえる場合があります。人事に「住民税の特別徴収（給料からの天引き）を次の会社で続けたい」と伝えます。

例）10月末に退職し、自分で払う場合は、11月〜翌年5月分の納付書が市区町村から届きます。

どれにするかは、最後の給料の計算前に、人事へメールで伝えます。

## ステップ5 ハローワークで失業手当の手続きをする（Bの人）

1. 離職票-1・-2が届いたら、住所地のハローワークへ行きます。事前に「ハローワークインターネットサービス」で求職者マイページを作っておくと、窓口で書く量が減ります【要確認：画面名】。
2. 窓口で「失業手当の手続きに来ました」と伝え、「求職申込書」を書きます。「希望する職種」欄には、例）「一般事務」「経理事務」のように書きます。
3. 受給資格が決まると、「雇用保険説明会」の日時と、最初の「認定日」（失業の状態を確認する日）を伝えられます。

持ち物は、離職票-1・-2、マイナンバーカード（ない場合は通知カードと本人確認書類）、写真2枚（縦3cm×横2.4cm）、本人名義の通帳かキャッシュカードです【要確認：マイナンバーカードを毎回出せば写真を省ける場合がある】。

自己都合で退職した人は、手続きから7日間の待期のあと、さらに1か月は支給されません。これを給付制限と呼びます【要確認：令和7年4月以降の期間。過去5年の自己都合退職の回数で変わる】。

## ステップ6 次の会社に書類を出す

入社時に、次の3つを出します。

- 源泉徴収票：年末調整で、前の会社の給料と合わせて計算するため
- 雇用保険被保険者証：雇用保険を引き継ぐため
- 基礎年金番号がわかる物：厚生年金に入るため

源泉徴収票が前の会社から届かないときの頼み方と、年末調整に間に合わなかったときの進め方は、別記事「年末調整の書類の書き方」の文例1と、つまずきやすい箇所の5にまとめています。

## つまずきやすい箇所と、その対処

1. **離職票が届かない**：退職から2週間たっても届かなければ、文例2で人事に催促します。それでも届かないときは、ハローワークに相談すると、ハローワークから会社へ連絡してもらえます【要確認：対応はハローワークごとに違う】。
2. **健康保険資格喪失証明書がない**：国民健康保険の窓口で、退職日がわかる別の書類（離職票や退職証明書）で受け付ける役所もあります。行く前に電話で「資格喪失証明書の代わりになる書類」を聞きます。
3. **任意継続の20日を過ぎた**：任意継続には入れません。国民健康保険に入ります。国民健康保険は14日を過ぎても入れますが、保険料は退職日の翌日までさかのぼって払います。
4. **休職中に退職する**：傷病手当金を受け取っている人は、退職日に出勤してはいけません。理由と、退職後も受け取り続ける条件は、別記事「傷病手当金の申請」の状況Bと、つまずきやすい箇所の1にまとめています。
5. **国民年金の納付書を待つ間に、払い忘れが心配**：国民年金の窓口で「国民年金保険料口座振替納付（変更）申出書」を出すと、口座から自動で引き落とされます。届出印と通帳を持っていきます。

## そのまま使える文例3つ

### 文例1 退職届

```
退職届

　私儀

　このたび、一身上の都合により、令和〇年〇月〇日をもって退職いたします。

令和〇年〇月〇日

〇〇部　〇〇〇〇（氏名）　印

株式会社〇〇
代表取締役　〇〇〇〇　様
```

会社の都合で辞める場合（倒産、解雇、退職勧奨）は「一身上の都合により」と書きません。「貴社の退職勧奨に応じ」のように、理由をそのまま書きます。

### 文例2 離職票の催促メール

```

退職日から〇日が経ちましたが、まだ届いておりません。

お手数ですが、次の2点を教えていただけますでしょうか。
1. ハローワークへの手続きはお済みでしょうか
2. 発送の予定日

送付先：〒〇〇〇-〇〇〇〇 〇〇県〇〇市〇〇 〇-〇-〇
電話：〇〇〇-〇〇〇〇-〇〇〇〇

```

### 文例3 家族の勤務先への扶養の依頼メール（家族から総務へ送る）

```

お世話になっております。〇〇部の〇〇です。
```

## 終わったかどうかの確認方法

次の表で、自分の状況の行がすべて「済」になれば完了です。

| 確認すること | A | B | C |
|---|---|---|---|
| 新しい健康保険の資格確認書か、資格情報のお知らせが届いた | ○ | ○ | ○ |
| 国民年金の納付書が届いた（届くまで1〜2か月） | 空白があれば○ | ○ | ― |
| 住民税の払い方を人事に伝え、返事をもらった | ○ | ○ | ○ |
| 雇用保険受給資格者証を受け取った | ― | ○ | ― |
| 次の会社に源泉徴収票などを出した | ○ | 入社時 | ― |

健康保険が切り替わったかは、マイナポータルの「健康保険証」の画面でも確かめられます【要確認：画面名と、反映までの日数】。
